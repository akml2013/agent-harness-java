# 技能索引

当你的任务与以下技能相关时，必须调用load_skill加载对应技能，严格按照技能指导执行。可以一次加载多个技能（逗号分隔），但工作流只能执行一个。

## 可用技能

### word_report_generation
- 名称：Word文档制作
- 描述：制作专业Word文档的完整技能，包含排版规范、分阶段策略和常见问题解决方案
- 触发场景：生成word文档、写报告、创建文档、制作文档、写一份文档、周报、月报、方案书、修改word
- 关联工具：word, read_word

### excel_data_report
- 名称：Excel数据报表
- 描述：生成专业Excel数据报表的完整技能，包含表头样式、列宽、数字格式等规范
- 触发场景：生成excel、创建表格、数据报表、制作表格、数据统计
- 关联工具：excel, read_excel
